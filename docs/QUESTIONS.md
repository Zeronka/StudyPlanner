# Вопросы для защиты



Что такое эндпоинт? Обработчик конкретного сочетания HTTP-метода и пути.

Что такое маршрутизация? Выбор обработчика по URL, методу и ограничениям маршрута.

Где сервер? Program.cs создаёт приложение и настраивает обработчики; Kestrel обслуживает HTTP.

Что такое DI? Контейнер предоставляет зависимости. TaskRepository зарегистрирован как Singleton — один экземпляр для процесса.

Почему Singleton? Все запросы видят общий список и одну очередь записи файла. Это не распределённая БД.

Зачем SemaphoreSlim? Чтобы параллельные запросы не перезаписывали изменения друг друга внутри одного процесса.

Почему async/await? Ожидание файловой операции или HTTP не требует удерживать поток в синхронном ожидании.

Что такое JSON? Текстовый формат представления объектов для обмена данными.

Что такое DTO? Модель входа TaskInput отделяет поля запроса от сущности с серверным Id.

Что такое CRUD? Create, Read, Update, Delete; здесь POST, GET, PUT, DELETE.

Чем PUT отличается от PATCH? PUT здесь передаёт полный набор изменяемых полей, PATCH обычно частичное изменение; PATCH в этом проекте не реализован.

Что означают коды? 200 — успех с ответом, 201 — создано, 204 — успех без тела, 400 — неверные данные, 404 — не найдено.

Где валидация? На фронтенде required/maxlength и на сервере Validate. Серверные проверки обязательны, потому что браузерные можно обойти.

Что такое AJAX? Асинхронный обмен с сервером без полной перезагрузки страницы; здесь используется fetch с JSON.

Почему нет CORS? Клиент и API находятся на одном origin. При выносе фронтенда на другой origin понадобится отдельная настройка.

Как защищается вывод названий? В JavaScript через textContent, в Razor стандартным экранированием; ввод пользователя не подставляется в HTML-разметку.

Как сохраняются данные? Новое состояние сначала записывается во временный файл, затем заменяет основной; рабочий список меняется только после успешной записи.

Чем плохо JSON-хранилище? Оно не подходит для нескольких независимых процессов и больших объёмов; нет полноценного SQL и транзакций СУБД.

Как работает .razor? Это компонент с разметкой и C#; здесь включён InteractiveServer. После первого интерактивного рендера выполняется HTTP-запрос списка.

Где REST? API использует ресурс tasks, идентификаторы в пути, HTTP-методы и коды статуса; это небольшой пример ресурсного HTTP API.

Как проверить понимание? Закрыть этот файл и самостоятельно объяснить путь одного запроса от кнопки до сохранения, затем изменить ограничение длины названия в коде.
