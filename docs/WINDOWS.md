# Запуск на ПК колледжа

## Что подготовить заранее

Сохранить ZIP с GitHub и исходники на флешку. Уточнить у преподавателя, есть ли .NET 10 SDK и разрешено ли его установить. Не менять настройки учебного ПК без разрешения. Для показа кода онлайн открыть репозиторий; для запуска скачать весь проект и распаковать.

## Запуск

В PowerShell из папки StudyPlanner.csproj:

```powershell
dotnet --list-sdks
dotnet run --project StudyPlanner.csproj --no-launch-profile --urls http://127.0.0.1:5088
```

Открыть http://127.0.0.1:5088 и не закрывать терминал. `--no-launch-profile` задаёт предсказуемый запуск, `--urls` оставляет сервер доступным только этому ПК.

## Возможные ошибки

- **dotnet не распознано:** SDK не установлен или терминал открыт до его установки. Проверить установку, открыть новый терминал.
- **NETSDK1045 / текущий SDK не поддерживает net10.0:** нужен SDK 10, а не только 8/9. Не менять TargetFramework вслепую.
- **Не удалось найти проект:** PowerShell открыт в другой папке; перейти `cd "полный путь к папке"`, где находится StudyPlanner.csproj.
- **Address already in use:** остановить свой прежний экземпляр Ctrl+C. Либо запустить с портом 5089 и открыть соответствующий адрес. Чужие процессы не завершать.
- **Access denied при записи:** распаковать проект в Документы пользователя, не запускать из ZIP или Program Files. Не запускать от администратора ради обхода прав.
- **Ошибка восстановления NuGet / нет сети:** заранее сделать сборку на разрешённом ПК с SDK. В проекте нет внешних PackageReference, но первый запуск SDK может потребовать доступ к источникам. Для предсказуемого офлайн-показа использовать заранее опубликованную сборку.
- **Страница недоступна:** проверить, что терминал показывает Listening и процесс работает; проверить точные http, IP и порт. Это HTTP localhost, не HTTPS и не адрес GitHub.
- **Повреждён tasks.json:** остановить сервер и сохранить копию App_Data. Исправить валидность JSON либо отдельно согласовать сброс демонстрационных данных. Не удалять пользовательский файл без копии.

## Вариант без SDK на экзаменационном ПК

На другом разрешённом ПК с .NET 10 SDK можно заранее подготовить отдельную сборку для Windows x64:

```powershell
dotnet publish StudyPlanner.csproj -c Release -r win-x64 --self-contained true -o publish/win-x64
```

Команда компилирует проект и кладёт приложение вместе с необходимым .NET runtime в отдельную папку. Это увеличивает размер, зато целевому Windows x64 не нужен SDK или установленный runtime. Требуются совместимая Windows и разрешение на запуск.

Скопировать **всю папку** publish/win-x64, включая wwwroot, на ПК колледжа. Открыть в ней PowerShell:

```powershell
.\StudyPlanner.exe --urls http://127.0.0.1:5088
```

Исходники взять отдельно для объяснения кода. Эта Windows-сборка сейчас не приложена и на реальном Windows не проверена. Перед экзаменом нужен пробный запуск на таком ПК.
